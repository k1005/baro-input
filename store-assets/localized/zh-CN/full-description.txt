把纸张和标签上的文字变成输入内容，减少逐字重打。

Baro Input 是一款 Android 辅助键盘，可从拍摄的照片或已保存的图片中识别文字和数字。选择需要的行，与原图核对后点按“插入”，即可填入当前输入框。

使用方法
1. 在 Android 键盘设置中启用 Baro Input。
2. 点按其他应用的输入框，切换到 Baro Input。
3. 拍照或选择设备中的图片。
4. 确认识别内容，然后点按“插入”。

适合日常输入
• 识别产品编号、标签、印刷便笺等内容
• 从多行文字中选择一行或全部内容
• 移除空格、移动光标、删除字符或添加分隔符
• 使用数字键盘修正识别出的编号
• 在其他应用中使用前，先用内置示例练习

支持四种识别语言
可识别英语、日语、中文和韩语。识别语言可独立于界面语言选择。界面支持英语、日语、韩语、简体中文和繁体中文，跟随设备设置中的受支持语言，其他语言则显示英语。

在设备上处理
识别模型随应用提供，无需联网即可使用。无需账号，没有广告。照片和识别结果不会上传至开发者服务器。输入会话结束后会清除临时结果。

Baro Input 是按需切换使用的独立键盘，不会向 Gboard 或三星键盘添加按钮。密码输入框无法使用扫描功能。相似字符或中文简繁字形可能被误识别，请在插入前与原图核对。如需输入新文字，请先插入结果，再用常用键盘编辑。
