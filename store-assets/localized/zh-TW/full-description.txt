把紙張和標籤上的文字變成輸入內容，減少逐字重打。

Baro Input 是一款 Android 輔助鍵盤，可從拍攝的照片或已儲存的圖片中辨識文字和數字。選擇需要的行，與原圖核對後點選「插入」，即可填入目前的輸入欄位。

使用方法
1. 在 Android 鍵盤設定中啟用 Baro Input。
2. 點選其他應用程式的輸入欄位，切換至 Baro Input。
3. 拍照或選擇裝置中的圖片。
4. 確認辨識內容，然後點選「插入」。

適合日常輸入
• 辨識產品編號、標籤、印刷便條等內容
• 從多行文字中選擇一行或全部內容
• 移除空格、移動游標、刪除字元或新增分隔符號
• 使用數字鍵盤修正辨識出的編號
• 在其他應用程式中使用前，先用內建範例練習

支援四種辨識語言
可辨識英語、日語、中文和韓語。辨識語言可獨立於介面語言選擇。介面支援英語、日語、韓語、簡體中文和繁體中文，跟隨裝置設定中的支援語言，其他語言則顯示英語。

在裝置上處理
辨識模型隨應用程式提供，無需連網即可使用。無需帳號，沒有廣告。照片和辨識結果不會上傳至開發者伺服器。輸入工作階段結束後會清除暫存結果。

Baro Input 是視需要切換使用的獨立鍵盤，不會向 Gboard 或三星鍵盤新增按鈕。密碼輸入欄位無法使用掃描功能。相似字元或中文簡繁字形可能被誤辨識，請在插入前與原圖核對。如需輸入新文字，請先插入結果，再用慣用鍵盤編輯。
