종이나 라벨의 글자를 길게 다시 입력하지 마세요.

바로입력은 카메라로 촬영하거나 저장된 사진에서 읽은 글자·숫자를 현재 입력칸에 넣는 Android 보조 키보드입니다. 필요한 줄을 고르고 원본과 비교한 뒤, 직접 ‘입력’을 누르면 내용이 들어갑니다.

이렇게 사용하세요
1. Android 키보드 설정에서 바로입력을 활성화합니다.
2. 다른 앱의 입력칸을 누르고 바로입력으로 전환합니다.
3. 카메라로 촬영하거나 기기에 저장된 이미지를 선택합니다.
4. 인식한 내용을 확인하고 ‘입력’을 누릅니다.

일상에서 편리하게
• 제품번호, 라벨, 인쇄된 메모와 글자 읽기
• 여러 줄 중 필요한 줄 또는 전체 내용 선택
• 공백 제거, 커서 이동, 글자 삭제와 구분자 추가
• 숫자 키패드로 인식한 번호 수정
• 다른 앱에서 사용하기 전, 내장 샘플로 입력 연습

4개 언어 문자 인식
한국어·영어·일본어·중국어를 읽습니다. 화면 언어와 별도로 인식 언어를 선택할 수 있습니다. 화면은 영어·일본어·한국어·중국어 간체·번체를 지원하며, 디바이스에 설정된 지원 언어를 따르고 그 외에는 영어로 표시됩니다.

기기 안에서 처리
문자 인식 모델이 앱에 포함되어 인터넷 없이 사용할 수 있습니다. 계정과 광고가 없으며, 사진과 인식 결과를 개발자 서버로 전송하지 않습니다. 입력기 세션이 끝나면 임시 결과를 지웁니다.

바로입력은 필요할 때 전환하는 별도 키보드입니다. 삼성 키보드나 Gboard에 버튼을 추가하는 앱은 아닙니다. 비밀번호 입력칸에서는 스캔을 사용할 수 없습니다. 유사 글자나 중국어 자형 등에서 오인식할 수 있으므로 입력 전에 원본과 비교해주세요. 새 글자를 입력하려면 결과를 넣은 뒤 기존 키보드로 편집하세요.
