# 사용자 흐름과 화면 명세 v0.1

## 제품의 두 표면

본체 앱은 최초 설정·권한·연습·환경설정을 담당한다. 실제 입력은 다른 앱 아래에 나타나는 IME 패널에서 진행한다. 시안에 보이는 상단 예제 입력 폼은 호스트 앱이며 우리 제품이 제어하는 화면이 아니다.

## 최초 사용

1. 소개: “글자와 숫자를 찍어서 입력하세요.” 주요 버튼 “사용 준비하기”.
2. 카메라 설명: “스캔하는 동안 카메라를 사용합니다.” 사용자가 선택하면 시스템 권한 요청. 거절 시 안내와 재시도, 영구 거절 시 앱 설정으로 이동.
3. 입력기 활성화: 시스템 입력기 설정으로 안내. 돌아오면 실제 활성화 상태 확인. 시스템 경고를 감추거나 자동 수락하지 않는다.
4. 연습: 가상의 제품번호를 제공하고 입력기 선택 → 스캔 → 삽입을 체험. 건너뛰기 제공.

## 반복 사용

입력칸 선택 → 시스템 입력기 전환 → 스캔 화면 → 화면 정지 / 영역 선택 → 인식 결과 확인 → 필요하면 수정 → 삽입.

입력기로 전환하면 화면이 보이는 동안 카메라를 열도록 설계하되 기술 검증 결과에 따라 명시적 “스캔 시작” 버튼이 필요한 경로로 변경할 수 있다. 스캐너를 켜는 것과 결과를 입력하는 것은 별도 행동이다.

## S1 스캔

- 헤더: “바로입력”, 텍스트/숫자 모드, “키보드 전환”.
- 카메라: 넓은 중앙 촬영 영역. 실제 인식된 텍스트에만 하이라이트.
- 안내: “번호가 선명하게 보이도록 맞춰주세요.”
- 주요 행동: “화면 정지”. 보조: 조명. 정지한 뒤 확대·영역 선택을 지원.
- 매 프레임 결과를 읽거나 진동시키지 않는다. 안정된 후보가 생겼을 때 한 번 알린다.

## S2 결과 확인

- 제목: “읽은 내용을 확인하세요”.
- 원본 영역을 결과 위에 표시. 숫자는 24–32sp 크기와 구별하기 쉬운 글꼴 사용.
- 예시: 원본 `0012 3456 7890` → 기본 결과 동일. “공백 제거”를 적용하면 `001234567890`으로 미리보기 변경.
- 주요 행동: “입력”. 보조 행동: “수정”, “다시 스캔”.
- OCR이 확실하다는 녹색 체크나 근거 없는 99% 정확도 표시는 사용하지 않는다.
- 인식된 O를 0으로 자동 치환하지 않는다. 숫자 모드의 허용 문자 밖 문자는 사용자 확인 대상으로 남긴다.

## S3 숫자 수정

- 읽은 숫자와 원본 유지. 커서/선택 상태 명확하게 표시.
- 숫자 패드, 삭제, 좌우 이동, 필요한 구분자만 제공.
- 단일 삭제와 전체 삭제를 분리하고 전체 삭제는 실행 취소 제공.
- 주요 행동 “수정 완료” → 결과 확인으로 복귀. 키보드 전환은 유지.

## S4 삽입 이후

InputConnection 전달 성공과 대상 앱의 최종 수용은 다를 수 있다. 전달 결과를 확인하고 “입력 내용을 확인하세요” 상태를 짧게 표시한다. 자동으로 엔터·전송·검색을 실행하지 않는다. 입력 후 카메라는 중지한다. 기존 입력기로 자동 복귀는 OS별 검증 전 약속하지 않고 전환 버튼을 제공한다.

## 오류와 예외

| 상태 | 안내 / 행동 |
|---|---|
| 카메라 권한 없음 | “카메라 사용을 허용하면 스캔할 수 있어요.” / 본체 앱 설정 경로 |
| 다른 앱이 카메라 사용 | “카메라를 사용할 수 없어요.” / 다시 시도, 키보드 전환 |
| 글자 미검출 | “글자를 찾지 못했어요.” / 조명 켜기, 다시 맞추기 |
| 선명하지 않음 | “조금 더 가까이, 잠시 멈춰주세요.” / 정지 촬영 |
| 여러 줄 인식 | 사용자가 필요한 줄·영역 선택. 첫 결과를 자동 입력하지 않음 |
| 입력칸 연결 해제 | 삽입 비활성화, “입력할 칸을 다시 선택해주세요.” |
| 비밀번호 필드 | “이 입력칸에서는 스캔을 사용할 수 없어요.” / 키보드 전환 |
| 모델 준비 실패 | “문자 인식을 준비하지 못했어요.” / 재시도, 키보드 전환 |
| 회전 / 작은 화면 | 스캔과 결과 패널 스크롤, 주요 버튼과 전환 유지 |

## 접근성 설계 기준 — 검증 전 목표

- 모든 주요 터치 영역 최소 48dp, 핵심 버튼 높이 56dp 이상.
- 일반 텍스트 대비 4.5:1 이상 목표. 실제 토큰 선정 후 측정.
- 본문 16sp 기준, 시스템 글자 크기 확대 시 잘림 없이 재배치.
- TalkBack은 번호 전체 읽기와 자리별 읽기를 구분한다. 결과가 생기면 포커스를 강제로 빼앗지 않고 한 번 알린다.
- 아이콘만 사용하지 않고 “조명”, “수정”, “키보드 전환” 등 레이블 제공.
- 조준 안내를 색상에만 의존하지 않는다. 촬영 안정화 피드백은 소리/진동 선택 가능.
- 시간 제한, 흔들리는 장식, 자동 닫힘 확인 화면 없음.
- Switch Access / 외부 키보드 사용 시 초점 순서와 주요 동작 접근 확인.

## 시각 방향 선택 후 할 일

선택된 시안에서 색·타이포·간격 토큰을 추출하고 S1~S4, 설정, 권한 거절, 입력 연결 해제 화면을 구체화한다. 정적 시안은 TalkBack이나 실제 카메라 작동을 검증하지 않는다.
