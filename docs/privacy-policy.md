# 바로입력 개인정보처리방침

시행일: 2026년 9월 9일

우모(이하 “개발자”)는 Android 앱 바로입력(패키지: im.umo.baro_input)의 개인정보 처리 방식을 다음과 같이 안내합니다. 개인정보 관련 문의와 권리 행사 요청은 ceo@umo.im으로 보내주세요.

## 1. 사진과 인식한 문자

바로입력은 사용자가 촬영하거나 시스템 파일 선택기에서 직접 선택한 이미지를 기기 안에서 처리하여 글자와 숫자를 인식합니다. 카메라 영상, 선택한 이미지와 인식 결과를 개발자의 서버로 전송하지 않습니다. 앱에는 인터넷 접근 권한이 없으며, 문자 인식 모델은 앱에 포함되어 있습니다.

이미지와 인식 결과는 기능을 수행하는 동안 메모리에서 임시로 처리합니다. 앱은 촬영 이미지를 사진첩에 저장하거나 인식 이력을 별도 파일로 보관하지 않습니다. 입력기 세션이 종료되면 해당 세션의 결과를 해제합니다. 사진 선택 후 입력기로 전달하기 위한 임시 요청은 최대 5분 동안 유지됩니다. 연습 화면의 결과는 해당 화면이 유지되는 동안 표시됩니다. 사용자가 원래 보관하던 사진은 앱에서 삭제하지 않습니다.

## 2. 다른 앱의 입력칸

바로입력은 Android 입력기 기능을 통해 현재 입력 대상의 앱 식별자, 입력칸 식별자와 입력 유형을 확인합니다. 이는 비밀번호 입력 제한과 잘못된 입력칸으로의 삽입 방지를 위해 사용하며 개발자에게 전송하지 않습니다. 사용자가 결과를 확인하고 ‘입력’을 누른 경우에만 해당 입력칸에 문자를 전달합니다. 입력된 이후의 정보는 대상 앱의 개인정보처리방침과 사용자의 설정에 따라 처리됩니다.

## 3. 권한과 사용자 선택

카메라 권한은 사용자가 촬영 기능을 이용할 때 필요하며 Android 설정에서 언제든지 철회할 수 있습니다. 카메라 권한을 거부해도 저장된 사진을 선택하여 읽을 수 있습니다. 사진 선택은 Android 시스템 파일 선택기를 사용하며 전체 사진첩 또는 저장소 접근 권한을 요청하지 않습니다. 입력기는 Android 설정에서 비활성화할 수 있습니다.

## 4. 포함된 소프트웨어와 기기 내 진단 정보

문자 인식에는 Google ML Kit의 앱 포함형 한국어·라틴 문자 인식 모델을 사용합니다. ML Kit는 기능 실행 과정에서 설치 식별자, 기기·앱 정보와 실행 성능 등의 진단 정보를 기기 내에서 처리할 수 있습니다. 이 앱의 배포 설정은 인터넷 및 네트워크 상태 권한을 제거하여 앱 자체의 네트워크 전송을 차단합니다. 사진과 인식 결과를 클라우드 문자 인식에 사용하지 않습니다. SDK 또는 권한 구성이 변경되는 경우 이 방침과 스토어의 데이터 보안 정보를 함께 갱신합니다.

Android, Google Play와 사용자가 선택한 외부 앱·웹사이트의 자체 데이터 처리는 각 제공자의 방침에 따릅니다.

## 5. 계정, 광고 및 고객지원

바로입력에는 회원가입, 광고, 앱 내 결제 기능이 없습니다. 개발자는 앱에서 처리한 사진이나 인식 결과를 수집·판매하지 않습니다.

사용자가 고객지원 이메일을 보내면 개발자는 이메일 주소와 사용자가 작성한 문의 내용을 문의 응답 및 문제 해결을 위해 처리합니다. 문의에 사진이나 민감한 정보를 불필요하게 포함하지 마세요. 문의 정보는 처리가 끝나 보관 필요가 없어지면 삭제하며, 법령에 따른 보관 의무가 있는 경우 해당 기간 동안 보관합니다. 열람·정정·삭제 등 요청은 ceo@umo.im으로 할 수 있습니다.

## 6. 삭제와 방침 변경

앱의 기기 내 데이터는 Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하여 삭제할 수 있습니다. 원본 사진 및 다른 앱에 입력한 내용은 해당 위치에서 별도로 관리해야 합니다. 앱에는 계정이 없으므로 별도의 계정 삭제 절차가 없습니다.

처리 방식이 변경되면 이 페이지의 내용과 시행일을 갱신합니다. 이용자의 권리에 중요한 변경은 앱 또는 스토어 안내를 통해 알립니다.
