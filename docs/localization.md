# 언어 지원

화면은 영어를 기본으로 하며 Android의 디바이스 언어 우선순위에 따라 영어, 일본어, 한국어, 중국어 간체·번체를 선택한다. 지원 언어가 없으면 영어를 표시한다. Android 13 이상의 시스템 앱별 언어 설정에서도 지원 언어를 선택할 수 있다. 한국어 앱 이름은 바로입력, 다른 언어에서는 Baro Input이다.

모든 화면 문구 82개와 앱 내 개인정보처리방침을 각 언어로 제공한다. 기본 리소스는 `values`, 번역은 `values-ja`, `values-ko`, `values-zh`(간체), `values-b+zh+Hant`(번체)다. 개인정보처리방침은 같은 언어 한정자를 사용하는 `raw` 리소스에서 읽는다. 의존성에만 존재하는 번역 때문에 앱 언어 선택이 바뀌지 않도록 빌드에 포함할 언어도 제한한다.

OCR은 화면 언어와 독립적이다. 텍스트 모드에서 인식 언어를 선택하고, 숫자 모드에서는 기존 라틴 문자 모델을 사용한다. 초기 OCR 언어는 디바이스의 첫 지원 언어이며 지원 언어가 없으면 영어다. 사용자가 변경하면 그 선택만 SharedPreferences에 저장하여 사진 선택 복귀 및 새 입력 세션에서도 유지한다. 이미지와 인식 결과는 저장하지 않는다. 중국어 모델은 간체·번체에 공통으로 사용한다.

한국어·일본어·중국어·라틴 모델을 모두 앱에 포함하며, 실제 사용한 모델만 초기화하고 입력 패널 종료 시 해제한다. 인터넷 및 네트워크 상태 권한 제거를 유지한다. 모델 추가로 설치 용량은 증가한다.

검증 명령:

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
.\gradlew.bat connectedDebugAndroidTest
```

`LocalizationTest`는 지역별 언어, 영어 대체 표시, 언어 우선순위, 개인정보처리방침 언어, OCR 선택 유지 및 작은 화면의 하단 동작을 검증한다. `OfflineOcrTest`는 실제 번들 모델로 영어·일본어·한국어·중국어 간체·번체 문장과 숫자를 읽는다. 영어·일본어·한국어 샘플은 공백을 제외한 완전 일치, 중국어는 문자 편집 거리 25% 이하 및 마지막 숫자 완전 일치로 모델 연결을 검증하고 실제 출력을 로그에 남긴다. 합성 인쇄 문장 테스트는 실제 촬영 환경의 인식 품질을 보장하지 않는다.

API 34 에뮬레이터에서 중국어 샘플은 `产品编号`를 `产品編号`, `中文辨識 產品編號`를 `中文辦識産品編號`로 읽었다. 간체·번체 및 유사 글자의 혼동은 남아 있으며 자동 교정하지 않는다. 원본 비교 및 사용자 확인 후 입력하는 흐름을 유지한다.

구현 기준: [Android 다국어 리소스](https://developer.android.com/training/basics/supporting-devices/languages), [앱별 언어](https://developer.android.com/guide/topics/resources/app-languages), [ML Kit Android 문자 인식](https://developers.google.com/ml-kit/vision/text-recognition/v2/android).
